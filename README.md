# Análisis de Vehículos en Venta

## Descripción
Aplicación web para el análisis exploratorio de datos de anuncios de vehículos en venta en Estados Unidos.

## URL de la aplicación
https://mi-proyecto7.onrender.com

## Organización del repositorio
- `app.py` → Aplicación web con Streamlit
- `vehicles_us.csv` → Dataset de vehículos
- `requirements.txt` → Librerías necesarias
- `notebooks/EDA.ipynb` → Análisis exploratorio de datos

## Cómo correr el proyecto localmente
1. Clona el repositorio
2. Crea un entorno virtual: `python -m venv vehicles_env`
3. Actívalo: `vehicles_env\Scripts\activate`
4. Instala las dependencias: `pip install -r requirements.txt`
5. Ejecuta la app: `streamlit run app.py`
