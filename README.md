# mi_proyecto7
Un repositorio para mi proyecto de sprint 7
# Análisis de Vehículos en Venta

## Descripción
Aplicación web para el análisis exploratorio de datos de anuncios de vehículos en venta en Estados Unidos.

## Funcionalidad
- Histograma de distribución de precios
- Gráfico de dispersión entre odómetro y precio

## Tecnologías utilizadas
- Python
- Pandas
- Plotly Express
- Streamlit
